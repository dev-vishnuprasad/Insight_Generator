# Income Classification Web Application

## Overview
This is a Flask-based web application designed to preprocess datasets, train machine learning models, and generate visualizations and insights for income classification. The application allows users to upload CSV files, preprocess data, train RandomForest and XGBoost models, generate feature importance plots, and derive insights using the Gemini AI model.

## Features
- **Data Upload**: Upload training and test CSV files.
- **Preprocessing**: Customizable preprocessing scripts to handle missing values, encode categorical variables, and remove duplicates.
- **Model Training**: Train RandomForest and XGBoost models with hyperparameter tuning via GridSearchCV.
- **Visualization**: Generate feature importance plots, histograms, and correlation heatmaps.
- **Insights Generation**: Use Gemini AI to generate detailed insights based on model performance and feature distributions.
- **JSON Outputs**: Save model results, feature importances, and distribution data in JSON format.

## Installation
1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Create a Virtual Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Set Environment Variables**:
   - Set the `gemini_key` environment variable for the Gemini API:
     ```bash
     export gemini_key='your-gemini-api-key'  # On Windows: set gemini_key=your-gemini-api-key
     ```

5. **Create Necessary Directories**:
   Ensure the `uploads`, `preprocessed`, `output`, and `model` directories exist:
   ```bash
   mkdir -p uploads preprocessed output model
   ```

## Usage
1. **Run the Application**:
   ```bash
   python app.py
   ```
   The application will start in debug mode on `http://127.0.0.1:5000`.

2. **Access the Web Interface**:
   - Open a browser and navigate to `http://127.0.0.1:5000`.
   - Upload two CSV files (train and test data) via the upload page.
   - Edit the preprocessing script if needed, then proceed to preprocess the data.
   - Generate plots and train models.
   - View insights generated by the Gemini model, along with visualizations.

3. **Expected Data Format**:
   The default preprocessing script expects a dataset with columns like `age`, `workclass`, `education`, `income`, etc. (see `preprocess_script.py`). Modify the script for custom datasets.

## Notes
- The `classify.py` script is incomplete and not integrated into the main workflow.
- Ensure the Gemini API key is valid and has appropriate permissions.
- The application assumes the dataset has an `income` column as the target variable. Update `target_column` in `preprocess_script.py` for other datasets.
- The application saves plots and JSON files in the `output/` directory.
